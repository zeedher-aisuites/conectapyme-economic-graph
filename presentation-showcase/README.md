# Presentación ejecutiva de ConectaPyME

Presentación interactiva local de 16 diapositivas principales y 14 anexos. Utiliza datos sintéticos y escenarios financieros hipotéticos.

Desde la **raíz del repositorio**, ejecuta:

```powershell
py -m http.server 8765 --bind 127.0.0.1 --directory presentation-showcase
```

Abre http://127.0.0.1:8765/ para ver las diapositivas. El botón **Presentador** abre la vista de notas. Abre ambas ventanas en el mismo navegador y origen para sincronizarlas. Usa el menú de evidencias de cada diapositiva para consultar los paneles disponibles.

Se incluye `ConectaPyME.pdf` (30 páginas, 16 principales y 14 anexos), generado como copia estática de las diapositivas públicas. Los paneles interactivos solo están disponibles en la versión HTML.

El prototipo no representa resultados comerciales reales y no incluye un modelo entrenado. La ayuda de IA utilizada en código, pruebas, documentación y presentación se reconoce en el README principal.
